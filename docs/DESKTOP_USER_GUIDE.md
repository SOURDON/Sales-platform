# Приложение «Фотографы» на компьютере

Краткая инструкция для сотрудников (без программирования).

## Установка

### macOS

1. Откройте файл `Фотографы_*.dmg` из папки, которую передал IT.
2. Перетащите приложение **Фотографы** в папку **Программы**.
3. Запустите из **Программы**. При первом запуске macOS может спросить разрешение — нажмите **Открыть**.

### Windows

1. Запустите установщик `Фотографы_*_x64-setup.exe`.
2. Следуйте шагам мастера установки.
3. Запустите **Фотографы** из меню «Пуск» или с рабочего стола.

## Вход

- Логин и пароль — **те же**, что на сайте в браузере.
- После входа данные подтягиваются с сервера при наличии интернета.

## Интернет и офлайн

Вверху экрана показывается статус:

| Сообщение | Значение |
|-----------|----------|
| Нет сети | Интернета нет; можно смотреть сохранённые данные и вносить операции в очередь |
| Синхронизация… | Есть сеть, отправляются накопленные действия |
| (баннер скрыт) | Всё синхронизировано |

Когда интернет появится, приложение **само отправит** очередь на сервер.

### Что работает без интернета

| Роль | Просмотр | Действия |
|------|----------|----------|
| Админ точки | товары, смена, продажи | продажи, списания, смена, персонал |
| Директор | сводка, финансы, склад | финансы, одобрения, планы выручки |
| Бухгалтер | финансы, отчёты | доходы, расходы, балансы |
| Управляющий | главная (сводка, планы) | — |

## Обновление приложения

IT выдаёт новый установщик (`.dmg` или `.exe`). Установите поверх старой версии или удалите старую и установите новую — сессия (логин) обычно сохраняется.

## Если при входе «Load failed» или «не достучалось до сервера»

Это **не неверный пароль**, а блокировка запроса с компьютера (CORS на Render).

На [Render](https://dashboard.render.com) → сервис **sales-platform-1** → **Environment** → переменная **`CORS_ORIGIN`**:

в конец через запятую добавьте:

```text
,tauri://localhost,https://tauri.localhost
```

Сохраните и нажмите **Manual Deploy**. Через 2–3 минуты снова войдите в приложение.

## Если что-то не работает

1. Проверьте интернет (Wi‑Fi / кабель).
2. Закройте приложение полностью и откройте снова.
3. Если ошибка входа — уточните у IT адрес сервера (настраивается при сборке приложения).
4. Сообщите IT: роль, что делали, текст ошибки на экране.

Техническая сборка и разработка: `desktop/README.md`, план: `docs/DESKTOP_APP.md`.
