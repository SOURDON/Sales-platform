# Веб-приложение (телефон + браузер)

**Контекст для основного чата агента — правки веба без отвлечения на Tauri.**

## Во время разработки ПК-версии

- Веб **продолжает работать** и деплоиться как сейчас.
- Десктоп — **тот же** `frontend/` + позже папка `desktop/`; крупные ломающие API согласовывать с `docs/DESKTOP_APP.md`.
- Офлайн на телефоне для 4 ролей **не обязателен**; при необходимости — отдельная задача (PWA).

## Если трогаете API

- Сохраняйте обратную совместимость или версионируйте endpoint.
- Мутации, которые должны работать офлайн на ПК, желательно принимать **`clientId`** / `saleId` для идемпотентности.

## Десктоп-трек

Прогресс и задачи ПК — только в **`docs/DESKTOP_APP.md`**, отдельный Agent-чат.

## Первое сообщение в «веб»-чате

```
Правим веб (frontend/backend), деплой как обычно.
Десктоп и Tauri не трогаем — см. docs/DESKTOP_APP.md в другом чате.
```
